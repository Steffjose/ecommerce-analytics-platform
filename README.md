# ecommerce-analytics-platform
End-to-end e-commerce analytics platform built with MySQL, Python &amp; Power BI — covers database design, SQL analytics, statistical analysis, ML models (Prophet, Random Forest), and interactive dashboards for revenue optimization and customer intelligence.


E-Commerce Analytics Platform
End-to-end analytics pipeline built with MySQL, Python, and Power BI to optimize revenue and customer intelligence for an e-commerce business.

Problem Statement
A fast-growing e-commerce company faced a 68% cart abandonment rate, 22% return rate, frequent inventory stockouts, and only 78% on-time delivery. This platform provides 360° visibility to address these issues.

Key Results

Sales forecast MAPE: 13.51% using Prophet


57 high churn risk customers identified


22% return rate — delivery delay confirmed as primary driver


Marketing ROI: 39.14% blended across all channels




How to Run

Run SQL/ecommerce_create_and_load.sql in MySQL Workbench


Update DB credentials in Python notebooks and run in order


Open PowerBI/ecommerce_dashboard.pbix and refresh data source
